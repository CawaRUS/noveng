# NOVENG (Novel Engine) v0.6.0

Легковесный движок для текстовых новелл на **C++**, разработанный с упором на производительность и простоту написания сценариев.

> **Разработчик:** [TheCawa](https://cawas.duckdns.org/me.html)
>
> **Стек:** C++17, miniaudio, nlohmann/json

---

## Особенности

* **Сценарный движок:** игра пишется в обычном `.txt` файле с командами в фигурных скобках.
* **Типизированные переменные:** `int`, `float`, `bool`, `string`.
* **Скриптовые выражения:** арифметика, сравнения, логика `&&`/`||`, переменные `$var$`.
* **Система сохранений:** неограниченные ручные слоты, автосохранение с ротацией (5 слотов), метаданные (дата, глава, прогресс).
* **Экран загрузки/сохранения:** список слотов с автосохранениями и ручными сохранениями.
* **Меню паузы:** вызов по `Esc` во время игры с пунктами продолжить, загрузить, сохранить, настройки, выход в главное меню.
* **Аудио:** фоновая музыка MP3/WAV с циклами, звуковые эффекты, громкость.
* **Текстовый UI:** ANSI-цвета для персонажей, баннеры, эффект тряски экрана.
* **Глобальные переменные:** persistent-данные между прохождениями (флаги концовок, New Game+).
* **Шифрование:** ресурсы и сохранения защищены ChaCha20 (опционально при сборке с `DECRYPT=true`).

## Структура сценария

Сценарии хранятся в `res/scenario/`. Движок поддерживает три типа строк:

1. **Имя персонажа:** `[Имя]` - задаёт текущего говорящего.
2. **Текст:** обычная строка текста для вывода с эффектом печати.
3. **Команды:** пишутся в фигурных скобках `{команда:аргументы}`.

### Доступные команды

Подробное описание всех команд читайте в [`documentation.md`](documentation.md).

## Управление

### Во время игры

| Клавиша | Действие |
| :--- | :--- |
| **Enter** | Пропустить анимацию текста / следующий диалог. |
| **Esc** | Открыть меню паузы. |
| **S** | Быстрое сохранение в слот 1. |
| **L** | Быстрая загрузка последнего сохранения. |
| **H** | Перерисовать экран (история). |
| **M** | Вкл./выкл. звук. |
| **Space** | Поставить текст на паузу (её раз - продолжить). |

### В меню

| Клавиша | Действие |
| :--- | :--- |
| **↑ / ↓** | Навигация по пунктам. |
| **Enter** | Выбрать пункт. |
| **Esc** | Назад / выход. |

### Экран загрузки/сохранения

| Клавиша | Действие |
| :--- | :--- |
| **↑ / ↓** | Навигация по слотам. |
| **Enter** | Загрузить / сохранить в выбранный слот. |
| **Del** | Удалить выбранное сохранение (только в режиме загрузки). |
| **Esc** | Назад. |

## Сборка

Проект использует простой Makefile.

**Зависимости:**

* `miniaudio.h` (в комплекте)
* `json.hpp` (nlohmann/json, в комплекте)
* Компилятор с поддержкой C++17 (GCC/MSVC)

**Требуется MinGW-w64**, в проекте лежат только ключевые инструменты (`make`, `g++`). Остальная часть MinGW-w64 должна быть скачана и прописана в `PATH`.

Ссылка на скачивание MinGW-w64:  
<https://github.com/brechtsanders/winlibs_mingw>

**Сборка:**

```bash
./make/make.exe -j2
```

**Запуск:**

```bash
./make/make.exe run
```

Для сборки с шифрованием ресурсов задайте ключ через переменную окружения:

```bash
export NOVENG_ASSET_KEY="your_secret_key"
./make/make.exe -j2
```
